# DigitalEdity – Sales Performance Dashboard (August 2025)
## Project Objective
-The primary goal of this project is to analyze and visualize Edify’s sales performance across different products, categories, and regions for August 2025.
-The dashboard provides an interactive overview of sales, profits, units sold, discounts, and growth trends to assist management in making informed business decisions.

## Dataset Used
- <a href="https://github.com/chamundeswari1212/DigitalEdify-Sales-Performance-Dashboard-Power-BI-Project-/blob/README/Project1_RawData.xlsx">Customers-Sales Dataset Store</a>
- Data Source: Edify internal sales database (2020–2025)
- Data Fields Include:
   > Product Name
   > Sales Amount (₹)
   > Profit Amount (₹)
   > Units Sold
   > Discount Amount
   > Category / Campaign (e.g., Diwali Bonanza, Summer Sale)
   > State & City

## Key Questions (KPIs)
- What is the total sales, profit, and units sold for August 2025?
- How does the current year’s sales compare to last year (LY Sales)?
- Which states and cities contribute most to sales?
- Which are the Top 5 performing products by Sales and Profit?
- What is the average discount across different campaigns?

-Dashboard Interaction - <a href="https://github.com/chamundeswari1212/DigitalEdify-Sales-Performance-Dashboard-Power-BI-Project-/blob/README/Screenshot%202025-10-30%20183355.png">View Dashboard</a>

## Process
- Verify data for any missing values and anomalies, and sort out the same.
- Made sure data is consistent and clean with respect to data type, data format and values used.
- Created pivot tables according to the questions asked.
- Merge all pivot tables into one dashboard and apply slicer to make dynamic.
